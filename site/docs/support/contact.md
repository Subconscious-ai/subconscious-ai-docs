# Contact

**Product support and questions**: join our
[Discord](https://discord.gg/3bgj4ZhABz) and ask in the `#support` channels.

**Press**: press@subconscious.ai

**Commercial**: ethicsboard@subconscious.ai

When reporting a problem with a run, include the run id and the exact request
body. Without the run id we cannot look up what happened.
